# qThroneMobile 3.3.1 beta 3

- Новый стиль интерфейса: только чёрный OLED и белая тема, больше скруглений, плавные анимации, анимированная кнопка подключения и серверы в выдвижной шторке. Включается во «Внешнем виде», по умолчанию остаётся классический.
- В классическом стиле экраны, диалоги и поля ввода приведены к одним размерам и скруглениям, анимации везде одинаково быстрые.
- Окно генерации хешей переделано: вход VK открывается прямо в нём, виден ход создания, выход из окна больше не просит войти снова.
- В режиме «Созданные в клиенте» хеши видно в настройках профиля и можно выбрать нужные.
- WS и gRPC для Trojan и VLESS теперь работают на Xray, как в других клиентах, это исправляет профили с панелей вроде 3x-ui 3.11. Учитывается параметр authority.
- Обновлены OpenFlux до 0.17.1 и MasterDNS.
- HTTPS-прокси по IP без SNI теперь подключается. Проверка сертификата для такого адреса отключена, с указанным SNI она работает.
- Проверка задержки по умолчанию идёт через HTTPS.
- Появились свои профили маршрутизации Happ и Incy без подписки, а в настройках пояснено, как они работают вместе с общей маршрутизацией.
- Автовыбор учитывает страну по флагу в названии, если профиль ещё не проходил IP-тест.
- Флаг и страна выхода в уведомлении обновляются при смене сервера в автовыборе.
- Добавлена защита от определения адреса сервера через tun0 приложениями вне VPN. Её можно отключить в настройках TUN.
- В значок профиля подходит любой флаг, в том числе белый.
- Сортировка по задержке не ждёт конца проверки большой подписки.
- Долгое нажатие на шапку группы открывает её настройки, двойное открывает управление группами. Пункты «Настройки» и «Редактировать» объединены.
- Название из подписки заменяет адрес в заголовке группы.
- При проверке OpenFlux больше нет надписи «Авторизация VK».
- На Android 7 используются встроенные корневые сертификаты, это должно устранить проблемы с подключением.
- Импорт профилей Soar из SlipNet 2.5.6.
