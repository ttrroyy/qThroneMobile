# qThroneMobile 2.8

- Свой DNS у профиля маршрутизации. В редакторе профиля маршрутизации появился раздел DNS: можно оставить общие настройки или задать для этого профиля свои удалённый и прямой DNS, DNS по умолчанию, DNS-маршрутизацию и FakeIP. Пока такой профиль выбран, его серверы заменяют общие, а в Настройки › DNS об этом написано сверху. Недавние серверы предлагаются списком. Свой DNS сохраняется при обмене профилем и в резервной копии, маршрутизация подписки по-прежнему использует свой DNS.
- Правила маршрутизации можно выключать, не удаляя. У каждого правила в профиле появился переключатель, а в быстром редакторе маршрутов пункт «Выключить». Выключенное правило остаётся в профиле, но не попадает в конфигурацию. При обновлении удалённого профиля выключенные правила остаются выключенными.
- В правилах маршрутизации появились фрагментация TLS и фрагментация TLS-записей для подходящих соединений, с задержкой фрагментации.
- Автовыбор может брать серверы сразу из нескольких групп. В поле «Серверы из» теперь можно отметить несколько групп, каждый сервер идёт через прокси входа и выхода своей группы. Профили автовыбора с одной группой работают как раньше.
- Страну выхода можно не определять. В Настройки › Ядро появился раздел «Страна выхода»: переключатель и выбор сервиса определения (ip-api.com, ipwho.is, ipinfo.io, ipapi.co, IP2Location.io, FreeIPAPI, Cloudflare или автоматически). В автоматическом режиме, если сервис не ответил, спрашивается следующий. Когда выключено, такие сервисы не запрашиваются.
- В mux для Xray появился выбор, что делать с UDP/443 (QUIC): отклонять, чтобы приложения перешли на TCP, пропускать через mux или отправлять мимо mux.
- Метод отклонения в правилах маршрутизации (default, drop, reply) теперь действительно применяется. Раньше он записывался в конфигурацию под неверным ключом.
- Копия удалённого профиля маршрутизации теперь становится обычным локальным профилем и не перезаписывается при обновлении оригинала.
- Ссылки TUIC, Juicity и Shadowsocks, в которых двоеточие между логином и паролем закодировано как %3A, теперь импортируются с правильным паролем.
- VLESS из Clash YAML с потоками, которые поддерживает только Xray, и с REALITY теперь получает то же ядро, что и такая же ссылка vless://.
- Новые профили AnyTLS, Hysteria, TUIC, Juicity, ShadowTLS, TrustTunnel и других протоколов с обязательным TLS больше не сохраняются с выключенным TLS.
- Регистрация WARP в режиме «Прокси» без подключения теперь идёт напрямую, а не с ошибкой.
