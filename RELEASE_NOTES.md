# qThroneMobile 3.2.1

- Настройка «Плитки на главном экране» теперь выбирает режим вместо отдельных плиток. «Расширенный» (по умолчанию) показывает все плитки. «Стандартный» оставляет только настройки и добавление, по углам сверху или снизу. Плитки больше не съезжаются к центру.

# qThroneMobile 3.2

- Ссылки `wdtt://`, по которым нельзя определить сервер, теперь по умолчанию работают на движке qWDTT. WDTT Plus по-прежнему выбирается вручную в профиле, и выбранный движок сохраняется.
- Новая подписка сразу получает название: из ссылки, из заголовка провайдера или по адресу сервера подписки. Обычная группа, как и раньше, создаётся без названия, если его не указать.
- Изменения профиля и группы сохраняются только галочкой. Крестик и «Назад» закрывают редактор без сохранения. У существующих групп теперь тоже появляется галочка.
- Тумблеры в профилях SSTP и других нативных транспортов больше не выглядят выключенными при повторном открытии. Например, «Использовать DNS сервера VPN» показывает сохранённое значение, а его изменение включает галочку.
- Во «Внешнем виде» появилась настройка «Плитки на главном экране»: сервисный режим, маршрутизирующий профиль, управление группами и обновления можно скрыть. Настройки и добавление показываются всегда.
- В настройки подписок добавлен пункт «Управление группами и подписками».
- Отключённые пункты настроек теперь выглядят неактивными. Например, «Подключиться к» затемнён, пока выключено «Подключаться при открытии».
- Исправлено моргание главного экрана при выходе из «Загрузки геоданных».

# qThroneMobile 3.1

- Старые ссылки `wdtt://` открываются как WDTT и по умолчанию работают на движке WDTT Plus: на серверах исходного WDTT теперь поднимаются все воркеры, а не один. В профиле можно вручную выбрать движок qWDTT с режимами WG и RAW для серверов qWDTT. Ссылки `qwdtt://` по-прежнему открываются как qWDTT.
- Добавлены ссылки и подписки панели WDTT в формате `wdtt://` + base64 JSON: адрес, порты, пароль, хеш, имя и идентификатор устройства берутся из ссылки.
- Ссылки WDTT с локальным портом `0` импортируются с портом по умолчанию 9000.
- В профиле CSQTT можно выбрать версию клиента: 2.5.0 и новее (по умолчанию) или 2.1.9 для серверов с исходным протоколом, привязанным к устройству. Обновление подписки сохраняет выбранные версию CSQTT и движок WDTT.
- Изменения в редакторе профиля сохраняются при выходе через «Назад» или крестик. Раньше без нажатия галочки, например, «Использовать DNS сервера VPN» в SSTP после выхода выключался снова.
- Когда плитки расположены внизу, меню плитки обновлений открывается вверх и видно целиком.
- Группа больше не берёт название из имени профиля или заголовка подписки. Если название не указано, оно остаётся пустым, и такую группу можно создать.
