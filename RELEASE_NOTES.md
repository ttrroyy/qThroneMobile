# qThroneMobile 3.3

- Исправлена подготовка геоданных Happ и Incy при проверке задержки и подключении. Полные конфигурации Xray используют геофайлы своей подписки, в том числе при отключённой маршрутизации провайдера.
- Исправлена загрузка геоданных с GitHub на Android 7. Проверка сертификатов сохранена.
- HTTPS-прокси отображаются как HTTPS. Добавлена проверка сохранения TLS при импорте, сохранении и экспорте профиля.
- Обновлено окно генерации хешей VK: видимый выбор хешей, понятные действия создания, применения к профилям и удаления.
- ID привязанного аккаунта VK отображается приглушённым цветом.
- Исправлен цвет курсора в полях ввода. Уменьшено скругление диалогов загрузки геоданных и других окон.
- Добавлен отступ между лентой групп и прокручиваемыми профилями, устранено наложение содержимого на ленту.
