# qThroneMobile 3.2.2

- Конфиги AmneziaVPN (`vpn://`) берут DNS из самого экспорта. Раньше строка `DNS = $PRIMARY_DNS, $SECONDARY_DNS` оставалась неподставленной, и WireGuard/AmneziaWG резолвил через удалённый DNS по умолчанию, который такие серверы часто не пропускают: туннель поднимался, но сайты не открывались. Профили, импортированные раньше, нужно импортировать заново.
- У новой группы галочка видна сразу, поэтому группу без названия и без изменений настроек теперь можно создать.
