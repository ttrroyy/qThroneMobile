# qThroneMobile 3.2.5

- В списке серверов рядом с протоколом показываются транспорт и защита: `VLESS / TCP / Reality`, `VLESS / XHTTP / TLS`, `Trojan / gRPC / TLS`. Hysteria 2 подписывается как `Hysteria 2`, а AmneziaWG с версией параметров: `AWG 1.0`, `AWG 1.5`, `AWG 2.0`, `AWG 3.0`, `AWG 3.1`. Обычный WireGuard остаётся `WireGuard`. Поиск по списку находит и по этим подписям.
- Главный экран перестраивает список один раз, когда группа или подписка меняется несколько раз подряд (например, при первом обновлении новой подписки), и не моргает.
- В стандартном режиме плиток найденное обновление снова показывается на главном экране кнопкой «Обновить до …» между плитками настроек и «+»: одно нажатие открывает обновление.
- В выборе приложений для VPN и для правил маршрутизации показываются все приложения, в том числе те, что сами не запрашивают доступ в интернет. Например, Gemini: он выходит в сеть через приложение Google, поэтому для него нужно отметить и Google.
- «Показывать системные приложения» стал тумблером, а курсор и маркеры выделения в поиске окрашены в акцентный цвет и видны на OLED-теме. Экран выбора приложений для правил маршрутизации оформлен так же, как экран режима VPN для приложений.
